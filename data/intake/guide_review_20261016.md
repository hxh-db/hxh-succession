## 読む順番と内容

1. 冒頭で舞台、複数のルールの関係、情報の確かさを説明。
2. 基本数値・王子の呼称と番号 → 船の構造 → 王子の状況。
3. 参加資格・開始・勝者・脱落の解釈 → 儀式と守護霊獣 → 念の基本用語。
4. 船内の立場 → 王妃所属兵と監視 → 初期配置の復元案 → 船内法と戒厳令 → 念講習会。
5. 三大マフィア・二線者 → 恋のエチュードの加入条件とレベル → 交渉ゲーム → 和平と念の契約。
6. 死後の呪いと詛贄者 → 三種の神器 → ビヨンドチームと渡航 → 暗黒大陸の資料。
7. 最後に、辞退・死亡と脱落・守護・神器・人数について誤解しやすい点をQ&Aで整理。

継承戦制度、船内法、念能力の発動条件、陣営同士の約束を同一のルールにしない。特に以下を区別した。

- 「生き残った手段を継承権では問わない」と、王子殺しに対する法的責任。
- 国王の脱落条件に関する回答と、生物学的な死だけで判定できるという断定。
- 守護霊獣の共通原則、王子本人の念、その他の念獣。
- 通常の捜査・準戒厳令・特殊戒厳令。72時間の監視聴取は該当事件の措置として説明。
- 講習での2週間という約束と、全員に適用される一般的な修行期間。
- 恋のエチュードの感染、完全加入、念の覚醒、感染集団を作る段階。最大23名と、その時点の人数。
- ロンギの契約対象・期限・更新・違反の罰・賞与・個人的な約束。血縁に関する推測。
- カミーラ本人の蘇生能力、私設兵の呪詛、ビヨンドの詛贄者。
