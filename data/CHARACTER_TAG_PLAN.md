# キャラクター一覧のタグ整理方針

更新日: 2026-10-01

## 結論

人物ごとの注釈は補足・未確定事項・出典確認のために残す。一覧で同じ条件の人物を集める用途には、複数付けられる構造化タグを使う。現行の `affiliation`、`camp`、`room`、`mission`、`target`、`children` は移行中も削除しない。所在はタグではなく、場所・確認時点・確度を別に表示する。

## 現状監査

- 人物197人。うち兵士102人。
- 兵士102人中43人は `affiliation` と `camp` が異なる。これはデータの誤りとは限らず、所属元から別陣営へ配置された人物を含む。
- 現行の人物カードは所属のバッジを一つだけ表示し、クリック時も所属のみで絞る。配置先と護衛対象は詳細欄や複数の絞り込みに分かれている。
- `target` が入っている13人は呪殺担当の標的であり、「護衛先」ではない。`camp` も配置・支持陣営を表すだけで、護衛任務の証拠にはしない。
- 王妃8人には `children` が構造化されているため、「第1王妃の子」等はそこから根拠をもって作れる。
- 所在の自動推定はまだ「現在地」と呼べない。たとえば `E415-005` はベンジャミン・オイト・ワブルを含み、出来事の部屋が1014号室だが、現行の推定関数は3人全員へその部屋を割り当てる。人物別の位置確認が必要。

## タグの種類

| 種類 | 表示例 | 判定の根拠 |
| --- | --- | --- |
| 所属元 | 第1王子私設兵、第1王妃所属兵 | 制度上の所属と兵種。表向きの所属と真の所属は必要なら分ける |
| 任務 | 監視、護衛、呪殺、憑依 | `mission` と原作の明示。任務が複数なら複数タグ。憑依は過去に成立した人格移動も含む |
| 護衛対象 | 第14王子護衛 | 護衛任務と対象王子の両方が確認できる場合のみ |
| 血縁・家族 | 第1王妃の子、同母兄弟、ビヨンドの実子 | 確定した親子関係から生成。「同母兄弟」は同じ母タグからたどれる |
| 特殊な立場 | ソエモノ、二線者、準協会員 | 原作で個人ごとに確認できた場合のみ。疑惑段階なら確定タグにしない |

同じ人物に複数の種類を付ける。例：バビマイナは「所属：第1王子私設兵」「任務：監視」。ワブル陣営への配属は詳細の配属情報で確認し、「護衛：第14王子」にはしない。サラヘルは「所属：第2王子私設兵」「任務：呪殺」「標的：第14王子」とし、「護衛」とは分ける。

「現在地」と「配置・配属先」は同一ではない。廊下へ移動しても所属や任務先が即座に変わるわけではないため、`camp` / `current_assignment` は裏側のデータとして残す。ただし初期のカードに配置タグは出さず、所在も「リアルタイムの現在地」ではなく「最後に記録された場所」として示す。

## データと画面の実装順

1. `character_tags.json` にタグ辞書と人物との対応を作り、まず8人へ所属・護衛対象・家族などの試行タグを付ける。分類と短い任務は既存の `type` / `mission` から全員分を表示する。試行タグは既存の人物データと王妃の `children` を根拠とし、全面展開前に原作話数を照合する。死亡したビンセントの過去の監視任務など、現在／過去の区別は引き続き要確認。
2. 人物カードのタグは「監視→第14王子」「憑依→シカク」のように短く表示し、種類は色で区別する。上部のタグ一覧は選択カテゴリの人物に該当するものだけを出す。兵士は兵種、マフィアは所属一家、王族は血縁を優先し、王族では任務・所属・対象の行を隠す。「関係王子」は広い関係を表す絞り込みであり、任務対象と同義ではない。カテゴリ・関係王子とタグは成立する組み合わせなら併用し、該当者がいない場合は競合する条件を解除する。カードのタグを押してもページ先頭へ移動させない。
3. 所在はタグとは別に扱う。既存の詳細欄には場所の情報があるが、複数人物が登場する出来事の場所を全員に割り当てる例があるため、現在地としてカードに強調表示しない。配属先・任務の履歴や、現在／過去のタグの区別を整えるまでは、従来の詳細欄と配置表を残す。
4. 試行画面で表示が分かりやすいか確認した後、原作根拠のあるタグを他の人物へ拡張する。その段階でタグごとの根拠話数・変更履歴と、必要なら複数タグのAND絞り込みを追加する。

## 注釈との役割分担

- 注釈：個別の事情、未確定の説、ユーザーの読書メモ。自分のメモであり、他の人物を自動的にまとめるための確定データにはしない。
- タグ：原作または構造化済みの確定データから裏付けられた、横断検索・比較のための関係。出典を追えるようにする。
- 遺伝上の父と公的な父、元の所属と現在の配置、護衛対象と呪殺標的を混同しない。

## カテゴリと重複の整理（2026-10-01）

- 「王子陣営」は「関係王子」と重複し、分類として範囲が曖昧なので廃止。どの王子に関係するかは「関係王子」で選ぶ。
- 「ハンター協会」はビヨンドチーム所属のハンターも含むカテゴリだったため「ハンター」に改称。ハンター協会という所属タグは試行データから外す。
- テータは従事者ではなく第4王子私設兵に修正。兵士カテゴリと私設兵タグで探せるようにする。
- 任務と王妃の子のタグは既存台帳から自動生成するため、同じタグの手動割当を削除。兵種の内部タグは所属表示に同じ表記がある場合に省略し、横断検索用の人員区分タグは表示する。上部の重複した兵種フィルタは人員区分へ統合する。
- 特殊な資格は「資格」カテゴリとして扱い、準協会員は個人資格が確認できた人物だけに付ける。テータにはユーザー指摘と第348・374話の照合に基づいて付与し、兵員数確保を受験目的とみる部分は推測と明記する。
- 十二支んは「所属」カテゴリの検索タグとし、元メンバーも含める。役割欄で現役・元を区別し、人物台帳に未登録のメンバーをこのタグ追加だけのために新規登録しない。
- 兵種と所属を別軸にし、人物カードでは確認できる王子私設兵・王妃所属兵を各王子／王妃の所属タグで探せるようにする。準協会員は資格タグで重ねて絞り込めるが、第374話の兵力図では私設兵数の内数。王妃所属兵タグは所属を表し、現在の配置先と同一視しない。
- 第374話の兵力図に合わせて「人員区分」タグを設け、私設兵・王妃所属兵・王室警備兵・協会員（護衛）を横断検索する。従事者は既存の人物グループで検索できる。準協会員は資格タグで別軸に残し、私設兵人数へ加算しない。人数表は同話時点の記載・配置であり、15名一律や現在の実数を意味しない。
- ソエモノなど他の特殊な立場、ビヨンドとの血縁、所属陣営も、確認できた人物に複数付くタグとして扱う。新しい最上位カテゴリは、横断検索できるだけの人物群と明確な分類軸がある場合に限って追加する。
