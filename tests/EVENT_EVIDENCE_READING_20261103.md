# 所在・未解決事項からの出来事と分類の共有（2026-11-03）

人物カードの所在リンク、未解決事項の通常の根拠、編集課題内の根拠を、既存の閲覧ルートへそろえた。表示する出来事とURLを一致させ、閉じる／戻るで元の条件・展開・スクロール・押したリンクやボタンを復元する。所在の候補グループ内も対象とし、同じ人物の根拠が複数ある場合は元の位置と出来事IDを照合する。

人物モーダル内の所在は既存の人物復帰を使う。所在の修飾キー、非左クリック、別ターゲット、download、既に処理されたクリックは標準のリンク操作を維持する。人物一覧からの操作では、人物詳細を開いていたことにしない。

未解決事項の分類は表示リンクの `t_question` でも保持する。既存の分類だけを受け入れ、不明値は「すべて」へ戻して不要なパラメータを削除する。「すべて」を選んだ場合もパラメータを削除する。分類変更後は新しい選択欄へフォーカスを戻す。基本情報の受信側は本文を開かず、明示的に全情報へ切り替えたときに指定の分類を表示する。

`location-question-return-browser.cjs` で1280・390・320pxを検証する。カード所在のURL・再読み込み・閉じる／戻る／進む・Ctrlクリック、通常と編集課題の根拠、分類と開閉・読み位置・フォーカス、共有・再読み込み・不明分類、別ブラウザ状態と別タブの基本表示を対象にする。6件の旧所在候補は既存の隔離シナリオで、カード内の展開と元リンクを検査する。公開データの所在を未判定へ戻さない。
